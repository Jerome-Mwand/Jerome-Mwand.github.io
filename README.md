# Jerome Mwandoki — Personal Portfolio

Public website: https://jerome-mwand.github.io/

This repository publishes the approved public portfolio in English and French, including research, projects, articles, gallery photos and downloadable CVs.

The archive excludes the Django database, credentials, private student files, LMS accounts, admin pages and phone number.

## Deployment

The GitHub Actions workflow extracts portfolio-public.zip and publishes it to GitHub Pages. Repository Settings > Pages must use GitHub Actions.

## Updates

Edit content in the separate local Django application, regenerate and review the public snapshot, then replace portfolio-public.zip.

Photographs and research figures retain their respective rights and source attributions. No open-source license is granted for them by making this repository public.
